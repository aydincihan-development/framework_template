# Release Notes — v0.1.0

Date: 2026-03-05

## Summary
First public baseline release of the AI-driven software development framework template.

## What is included
- Docs-driven delivery model:
  - scope doc (`FEAT/CHG`) -> precheck -> implementation -> validation -> DoD -> approval -> docs update
- Core governance docs:
  - `docs/AI_RULES.md`
  - `docs/TEST_STRATEGY.md`
  - `docs/DEFINITION_OF_DONE.md`
  - `docs/USER_GUIDE.md`
- Prompt templates:
  - `docs/preflight_prompt`
  - `docs/implement_prompt`
- Reusable feature/change templates:
  - `docs/features/_TEMPLATE.md`
  - `docs/features/CHG_TEMPLATE.md`
- Baseline architecture/stack defaults:
  - Next.js + Supabase + MUI
  - MUI X DataGrid and MUI X Charts standards
- Bootstrap automation:
  - `scripts/init-framework.sh`

## Intended usage
- For new projects that want fast but controlled human + AI collaboration.
- Baselines are defaults, not hard lock-in; override via `docs/DECISIONS.md`.

## Known limits (expected for early release)
- Version is `0.1.0` intentionally (framework still expected to evolve quickly).
- No CI pipeline enforcement included yet (process-first release).

## Upgrade impact
- N/A (initial release)
